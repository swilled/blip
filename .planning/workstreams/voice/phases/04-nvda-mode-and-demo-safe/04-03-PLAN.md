| Boundary | Description |
|----------|-------------|
| Public page to Blip result speech | Page labels, validation messages, and confirmation text are untrusted, observed input. |
| Demo profile and voice/audio to public room | Test values, transcripts, and recording may expose data to attendees or a remote STT service. |
| Venue network to offline fallback | A site or network failure changes the demo's source; the user must be told when it is offline. |
| Local fixtures to browser | Offline demo assets must not silently submit to the live public form or use remote assets. |
