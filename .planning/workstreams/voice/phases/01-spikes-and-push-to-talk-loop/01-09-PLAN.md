## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS keyboard to hook | Global hook observes every keystroke |
| hold delivery channel to window | In B a second loopback socket carries holds |
| speakers to microphone | Blip's own speech can re-enter the recognizer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Information disclosure | ptt-hook delivery | mitigate | Only the start/end result of the 3-key combo leaves the hook; no keycodes are sent, logged or stored |
| T-01-01 | Tampering | Blip's speech reaching the recognizer and confirming a gate | mitigate | Barge-in forced to ptt-only until GATE_08_PRESENT (Plan 08); echo filter is convenience only; real control is core's GATE-08; all speaks get speak.done including interrupted ones (Plan 07); the window never matches phrases |
| T-01-14 | Spoofing | global hold starting Blip | mitigate | Holds ignored before controller.activate() (test 1), which only the trusted gate keydown calls |
| T-01-10 | Spoofing | sidecar socket (B only) | mitigate | 127.0.0.1 bind, exact Origin http://127.0.0.1:7777, no inbound messages (test 2) |
| T-01-15 | Denial of service | stuck hold | mitigate | 10 s watchdog in ptt-state |
| T-01-SC | Tampering | npm installs | mitigate | No packages installed in this plan |
