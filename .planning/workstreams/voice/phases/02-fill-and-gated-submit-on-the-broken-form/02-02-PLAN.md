## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page -> templates | Labels, options, titles, errors are untrusted page strings that get spoken |
| STT -> matcher | Utterance text is untrusted; only exact phrase text may confirm |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | confirm.ts phraseMatches | mitigate | Exact token-sequence match, text only, no alternatives parameter, 25-row false table |
| T-02-06 | Information disclosure | templates.ts | mitigate | Use hasValue and "entered, hidden" for sensitive fields; marker-based property test |
| T-02-07 | Spoofing | phrase source | mitigate | Templates receive the phrase as an argument; nothing derives a phrase from page text |
| T-02-08 | Tampering | page labels spoken verbatim | mitigate | cleanSpoken strips control chars and caps length on every label/option/title |
| T-02-09 | Denial of service | regex on hostile text | mitigate | 200-char guard, token-list comparison, no RegExp built from labels, no nested quantifiers |
| T-02-10 | Tampering | field hijack via crafted labels | mitigate | Longest unique match; ambiguity returns a question instead of a fill |
</threat_model>
