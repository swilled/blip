<objective>
Phase goal (ROADMAP, Phase 2): On a real page in Chrome, Blip reads the form's controls and fills them the way a person would, and only ever reports the value the page actually holds.

This plan builds the read path of the real extension (PAGE-01, PAGE-03): a content-script DOM walk that produces every control's accessible-name candidates, role, value, required flag, options and error text, classifies every action with the fail-closed rules from plan 02-02, and a service-worker path that fans out over frames, merges and validates one Snapshot, versions it and replies to `snapshot.request`. It leads with the phase's end-to-end tracer on a real browser (a text field on a real page becomes a spoken field count for a voice-role client), then completes the DOM heuristics test-first in jsdom, then assembles the full walk.

Purpose: plan 02-05's fills resolve targets through the id table built here and apply the D-16 stale rule from the fingerprint history stored here; plan 02-06's verification matrix reads these snapshots.

Output: a content script (`content.js`) and service-worker modules that return schema-valid snapshots which the unchanged baseline builder accepts.

Roadmap success criteria served: 1 (snapshot content and truncation at the wire caps; the 8k-token trim is Phase 4 per D-20, F10), 2 (kinds, read side). Locked decisions: D-01 (reversibility costly, recorded on Task 1), D-05, D-07, D-16, D-17, D-18, D-20. Amendments: A-04 (visible semantics), A-06 (zod-free content bundle), research flags F4, F9 (ids), F8 (target tab, first cut).

Cross-origin iframes (D-17): the fan-out reads every frame the content script runs in (all_frames). The cross-origin test page arrives in plan 02-04 and its end-to-end check in plan 02-05. Time-box: if a cross-origin frame cannot be read by the Phase 2 midpoint, record a deferred item in the SUMMARY and have `captureTab` add the alert string `Part of this page could not be read.` once per unreachable visible frame instead of failing silently (D-17 fallback).
</objective>
