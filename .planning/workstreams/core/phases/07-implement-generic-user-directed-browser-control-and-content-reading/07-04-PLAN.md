Implement `scroll` to scroll a uniquely resolved current content block into view and `find` to find exact user-sourced text within currently visible captured text without clicking or submitting. Add jsdom and server tests for hidden/inert, nested, oversized, Unicode, empty, restricted, elapsed-budget, control-value exclusion, and a synthetic visible paragraph containing password/card/SSN shapes that is neither spoken nor sent to AGY.</action>
