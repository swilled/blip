# Plan 05-24: Classify AGY Repair Outcomes

## Objective

The previous bounded attempts stop intermittently during AGY repair, while the report only records the final model status. Add safe outcome categories to distinguish rejected structured output, provider failure, timeout, stale result, and successful repair, then use one fresh bounded synthetic attempt.

## Authorization and limits

The user authorized bounded synthetic AGY checks. This attempt uses the loopback survey, fictional inputs, a temporary cache, a harness-owned browser profile, a maximum of 900 seconds, eight provider dispatches, and eight synthetic voice utterances.

## Verification

- Unit coverage proves a structured-output rejection reports only its allowlisted category.
- Fake-brain preflight passes before consuming the fresh one-use claim.
- Live report contains only diagnostic enums, counters, and pass/fail fields; no prompt, output, page text, credentials, or account state.
- Full I3 success still requires exactly one grant-bound local submit.
