<objective>
Phase goal (ROADMAP, Phase 1): Both developers build against one frozen contract, and the whole loop (typed utterance -> server -> extension snapshot -> spoken reply) runs on one machine with no Chrome, no voice UI and no Claude.

This plan closes the loop (PROT-02): fake brain, grammar, session and reply, the fake extension, the typed REPL, and an in-process dev runner behind `npm run dev -- --brain=fake`. It leads with the tracer for the whole phase's headline capability (one utterance, "what's here", from REPL to server to fake extension to baseline form model to a reply with field count and required count), then expands to the rest of the grammar, the 1.5 s model-route delay, the fake extension's act handling and the REPL commands, then adds the runner and final verification.

Purpose: neither developer waits on Chrome, Claude or each other. Core's stand-ins fail closed (they never open a gate), so plan B for the demo is safe by construction.

Output: a single command that runs the walking skeleton offline, with integration tests over real sockets on port 0 for every step.

Roadmap success criteria served: 2 (the demo command and reply), 5 (voice client receives welcome and state, human check for the real UI), and the server side of I1. Locked decisions: D-14 (not-implemented elsewhere), D-16, D-21 to D-25.
</objective>
