<objective>
Phase goal (ROADMAP, Phase 1): Both developers build against one frozen contract, and the whole loop (typed utterance -> server -> extension snapshot -> spoken reply) runs on one machine with no Chrome, no voice UI and no Claude.

This plan stands up the npm-workspaces monorepo behind a single human-approved dependency gate, proves the registry-first protocol architecture end to end with a tracer (a frame built in one workspace, parsed in another, with role permissions derived from the same registry), then adds the domain schemas (ActionKind, Snapshot/RawElement, FormModel/Field, Intent, ActOp/ActRequest/ActResult) that the full message set (plan 01-02), the fixtures and baseline builder (01-03), the hub (01-04) and the skeleton (01-05) all build on.

Purpose: M0 (~h0.75) needs a contract both developers trust. Everything security-relevant here (sensitive-null, no confirm intent, per-role senders, fail-closed kinds) is a small pure schema or registry lookup that is unit tested before any socket exists.

Output: a green `npm install`, `npm run typecheck` and `npm test` on a monorepo whose `@blip/protocol` package already enforces the safety rules it will freeze at M0.

Roadmap success criteria served: 1 (M0 contract, schemas half). Locked decisions implemented here: D-04 (registry senders), D-06 (Envelope), D-07, D-08, D-09, D-10, D-11, D-15, D-18 (parse at the boundary), D-19, D-20.
