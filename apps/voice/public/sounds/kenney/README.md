# Kenney interface sounds

Blip uses these five short cues for listening, thinking, completion, blocked, and error feedback. The files are from Kenney's Interface Sounds pack, created by Kenney in 2020. They are distributed under CC0 1.0 Universal; the included `LICENSE.txt` records the terms.

Source pack: https://kenney.nl/assets/interface-sounds  
Repository mirror used to obtain the WAV files: https://github.com/Calinou/kenney-interface-sounds/tree/4596a49eaf5a533948d49a47467f606bcdea70ff/addons/kenney_interface_sounds

| Blip cue | Source file |
| --- | --- |
| Listening | `open_001.wav` |
| Thinking | `question_002.wav` |
| Done | `confirmation_001.wav` |
| Blocked | `back_002.wav` |
| Error | `error_002.wav` |

Kenney attribution is appreciated but not required.
